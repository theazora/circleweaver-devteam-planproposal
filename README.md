# Circle Weaver Rebuild Plan (portable export)

Open **`Circle-Weaver-Rebuild-Plan.html`** in any browser (Chrome, Edge, Firefox).

Works **offline**. Keep these files together:

| File | Purpose |
|------|---------|
| `Circle-Weaver-Rebuild-Plan.html` | The plan |
| `weaver-logo.png` | Title logo (required) |
| `mermaid.min.js` | Local diagram renderer (required) |
| `README.md` | This file |

Upload the whole folder to your repo so the HTML and `mermaid.min.js` stay side by side.
